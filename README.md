# 📄 Paper Grade Intelligence Dashboard

An AI-assisted decision-support layer for paper machine grade changes. It predicts Off-Spec risk during a grade transition, explains *why*, recommends corrective setpoints tagged with their source, tracks operator feedback on those suggestions, flags anomalous historical transitions, and exports a PDF snapshot of any session.

Built as a companion intelligence layer that sits alongside a Honeywell-style Quality Control System (QCS) MD Controller — it doesn't replace the control loop, it learns from historical transitions and gives operators (especially newer ones) context-aware guidance during high-loss grade-change events.

## Features

- **Live risk prediction** — probability of going Off-Spec at any point during a grade transition, plus an estimated time-to-stabilize
- **Explainable rationale** — every prediction is explained by comparing the current process state against historically successful transitions to the same grade, ranked by what the model actually weighs
- **Data-driven recommendations** — setpoint suggestions sourced from either hard recipe/actuator limits or nearest-neighbor historical successes, each tagged with its source and a confidence score
- **Operator feedback loop** — Accept/Reject decisions on recommendations are logged and summarized, so suggestion quality can be evaluated over time
- **Correlation discovery** — separates known control-loop correlations from correlations found in sensors that aren't part of the standard control loops (Wire Vacuum, Refiner Load, Draw Tension)
- **Trend & anomaly detection** — flags historical transitions that deviated significantly (peak deviation, stabilization time, off-spec rate) from other transitions to the same target grade
- **PDF session reports** — one-click downloadable PDF snapshot of any transition/time-step: risk, trajectory chart, rationale, and recommendations

## Setup

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd PaperGradeAI

python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS/Linux

pip install -r requirements.txt
```

## Running it

Run every command from the project root (`PaperGradeAI/`):

```bash
python src\generate_data.py          # generates data/paper_grade_data.csv
python src\train_model.py            # trains models/offspec_model.pkl + stabilization_model.pkl
python src\correlation_analysis.py   # builds models/correlation_summary.json + heatmap

streamlit run dashboard\app.py       # launches the dashboard
```

## Dashboard tabs

| Tab | What it shows |
|---|---|
| 🔴 Live Monitor | Risk %, ETA to stable, trajectory chart, recommendations with Accept/Reject, PDF report download |
| 🧭 Why? | Plain-English rationale for the current risk prediction |
| 🔗 Correlations | Heatmap + known vs. newly-discovered correlations with Off-Spec risk |
| 📈 Trends & Anomalies | Scatter of all historical transitions with statistical outliers flagged |
| ✅ Suggestion Quality | Acceptance rate of past recommendations, grouped by source |

## Notes on the data

`data/paper_grade_data.csv` is synthetic, generated by `generate_data.py` with a fixed random seed (`42`) for reproducibility. It's excluded from version control (see `.gitignore`) since it's fully regenerable — anyone cloning the repo can run `python src\generate_data.py` to produce the same dataset. The same applies to everything in `models/`, since those are derived artifacts of training, not source.
